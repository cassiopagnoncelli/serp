# Serp project

This is a brand new Serp project, a boilerplate Python API combining

- [x] Poetry package manager
- [x] FastAPI
- [x] SQL Model, Alembic for migrations
- [x] Redis
- [x] Celery with support to RabbitMQ and Redis
- [x] Flower, an UI for Celery
- [x] Uvicorn
- [x] Console
- [x] OpenAPI (automatic)
- [ ] Mailer
- [ ] Stripe payments
- [ ] Authentication (JWT, OAuth2, Google OAuth2, Microsoft, GitHub, Facebook)
- [ ] Models: Accounts, Plans
- [x] Storage
- [x] Pytest
- [ ] Dockerfile
- [x] Makefile
- [x] Docling
- [x] Image Magick
- [-] Tensor flow
- [ ] OpenAI, Anthropic, Gemini, Clarifai
- [ ] Explore: LangChain, HuggingFace
- [ ] MCP server
