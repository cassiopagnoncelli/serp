# Serp project

This is a brand new Serp project, a boilerplate Python API combining

- Poetry package manager
- FastAPI
- SQLModel
- Alembic (with Postgres, SQLite)
- Redis
- Celery with support to RabbitMQ and Redis
- Flower, an UI for Celery
- Uvicorn
- Console
- OpenAPI (automatic)
- Pytest
x Docker
x Makefile
x Authentication (JWT, OAuth2, Google OAuth2, Microsoft, GitHub, Facebook, Accounts, Plans)
x Storage
d Jinja2 (mailer templates)
d Strawberry GraphQL (api/gql)
d FastAPI Admin
