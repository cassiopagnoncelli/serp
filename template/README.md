# Serp project

This is a brand new Serp project, a full-fledged Python API combining a myriad of
features:

- ASGI server
- ORM, migrations
- Background jobs
- Mailer service
- Storage service
- Authentication
- AI tools
- Testing
- Linting
- Console
- Documentation
- Build tools

Project comes as is and as a result eventually you will have to upgrade
packages and resolve dependencies.
