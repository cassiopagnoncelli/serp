# Serp project

This is a brand new Serp project, a boilerplate Python API combining

- Poetry package manager
- FastAPI
- FastAPI Admin
- SQLModel
- Alembic (with Postgres, SQLite)
- Redis
- Celery with support to RabbitMQ and Redis
- Flower, an UI for Celery
- Uvicorn
- Console
- JWT
- Authentication (OAuth2, Google OAuth2)
- Docker
- Makefile
- OpenAPI (automatic)
- Storage
- Pytest
- Jinja (mailer templates)
- Strawberry GraphQL
- Console
- Model Wrapper
- Transactions
