# Serp project

This is a brand new Serp project, a boilerplate Python API combining

- [x] Poetry package manager
- [x] FastAPI
- [x] SQLModel
- [x] Alembic (with Postgres, SQLite)
- [x] Redis
- [x] Celery with support to RabbitMQ and Redis
- [x] Flower, an UI for Celery
- [x] Uvicorn
- [x] Console
- [x] OpenAPI (automatic)
- [ ] Authentication (JWT, OAuth2, Google OAuth2, Microsoft, GitHub, Facebook, Accounts, Plans)
- [ ] Storage
- [-] Pytest
- [ ] Dockerfile
- [-] Makefile
- [ ] Jinja2 (mailer templates)
- [ ] FastAPI Admin
- [ ] Stripe payments
- [ ] OpenAI, Clarifai, LangChain, HuggingFace, RAG
- [ ] Docling
- [x] Image Magick
